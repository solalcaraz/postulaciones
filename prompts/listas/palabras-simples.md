# Palabras simples

Equivalencias para escribir claro y, en inglés, a nivel B1. Adaptada de una lista de "plain English" (Plain English Campaign, Australian Government Style Manual, plainlanguage.gov), reducida a lo que importa en un CV y una carta. Si la palabra simple no encaja con el hecho del perfil, se cambia por el hecho o se corta la frase; nunca por un invento.

## Español
| En lugar de | Usar |
|---|---|
| utilizar | usar |
| implementar | armar, hacer |
| realizar, efectuar, llevar a cabo | hacer |
| poseer | tener |
| brindar | dar |
| facilitar | ayudar, dar |
| adquirir | aprender, conseguir |
| diversos | varios (y decir cuáles) |
| en base a | según |
| a través de | con |
| con el fin de | para |
| debido a que | porque |
| en el marco de | en |
| optimizar, potenciar | decir qué mejoró y cuánto (si hay número) |
| gestionar | decir qué se hizo |
| soluciones | decir cuáles |
| participé en | decir qué hiciste |

## English (B1)
| Instead of | Use |
|---|---|
| utilize, leverage | use |
| implement | build, set up |
| facilitate, assist | help |
| spearhead, orchestrate | the verb that matches the fact: built, made, worked on |
| demonstrate | show |
| ensure | make sure |
| enhance | improve |
| collaborate | work with |
| obtain | get |
| require | need |
| approximately | about |
| in order to | to |
| a variety of, numerous | many (and say which) |
| commence | start |
| endeavor | try |
| subsequently | then |
| additionally | also |
| therefore | so |
| robust, seamless, cutting-edge, innovative | delete, or say what it does |
| streamline | make simpler (only if the profile says so) |
| proficient in | say what you did with it |
