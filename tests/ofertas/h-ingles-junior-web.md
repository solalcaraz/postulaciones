Junior Web Developer (Support-Oriented) — Northwind Apps

Northwind Apps builds small web tools for local businesses. We are a team of eight and we work remotely from Argentina and Spain.

What you will do
- Fix bugs in our customer-facing web apps (React on the front end, Node.js and MongoDB on the back end).
- Reproduce issues reported by customers, find the cause and write a short note explaining what happened.
- Write and maintain automated tests for the fixes you ship.
- Read technical documentation in English and ask questions in writing when something is not clear.

What we are looking for
- Some hands-on experience with JavaScript or TypeScript and a web framework (personal, university or freelance projects count).
- Basic Git and GitHub workflow: branches, pull requests, code review.
- Experience answering customers or users, in person or remotely, is a plus.
- Reading and writing English at an intermediate level (B1/B2). Our written communication is in English and Spanish.
- Willingness to learn: this is a junior position.

We offer remote work, flexible hours and mentoring from a senior developer.
